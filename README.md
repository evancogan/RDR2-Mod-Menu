# AI Playground

A scratch RDR2 mod for experimenting, built on ScriptHookRDR2 .NET V2.

## Setup

- Requires ScriptHookRDR2 and ScriptHookRDR2 .NET V2 installed in the game folder.
- The game path is the `RDR2Dir` property in `AIPlayground/AIPlayground.csproj`.
- Building copies `AIPlayground.dll` into `<RDR2Dir>\scripts\` automatically.

## In-game

- `Insert` reloads scripts after a rebuild.
- `F8` opens the .NET console.
- `F9` shows a subtitle confirming AI Playground is loaded.
